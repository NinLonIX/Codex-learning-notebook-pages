Codex 订阅与计费
套餐额度 × API token 账单 × 省额度工作法
来源：AI 编程指南 · 04 订阅与计费 ｜ 教程更新 2026.09.01
01 · 先搞清楚：你在为什么付费？
工具免费，模型算力收费
Codex 的 CLI、桌面 App、IDE 和网页入口本身可以免费安装；真正产生费用的是模型处理你发来的内容、项目文件、命令结果和上下文。
输入 token+ 输出 token+ 上下文 token→ 算力成本
花钱多少与“问了几次”关系不大，更取决于每次塞进去多少上下文：大文件、长会话、巨型 AGENTS.md 都会加速消耗。
02 · 两套账：ChatGPT 订阅 vs API key
ChatGPT 订阅固定月费，包含一定用量限额；超出后可以购买积分续用。更适合个人日常使用。
API key没有月费，按实际 token 实时扣费；更适合 CI/CD、自动化脚本和无人值守任务。
云端功能订阅登录通常可用云端任务、自动代码审查和 Slack / GitHub 等工作区能力；API key 可能受限。
核心判断人用订阅，机器用 API key：前者图省心和可控，后者图按量精算和自动化。
两套账互不等同：ChatGPT 限额 / 积分，不等于 Platform API 余额；看错入口就会算错成本。
03 · 套餐怎么选？先看使用强度
Plus
参考 $20/月
个人起点、基准额度 Pro
参考 $100/月起
更高额度，重度用户 Business
按量 + 席位
团队管理与安全控制 Enterprise / Edu
联系销售
组织级部署与治理
个人通常从 Plus 开始；如果频繁撞限额，再评估 Pro 或积分。团队才重点看 Business 以上的席位、SSO / MFA、审计和数据治理能力。
Free / Go 是否含 Codex、能用多少，以当前官方定价页为准；不要把“可能能体验”理解成“承诺有完整编程额度”。
04 · 限额怎么算：5 小时窗口 + 积分续用
教程用官方快照解释：Codex 的本地消息和云端任务共享滚动计量窗口，常见理解是 5 小时一个周期，并可能另有每周上限；具体起算方式和数字会变化。
PlusGPT-5.5 本地消息参考：15–80 条 / 5 小时。
Pro 5x参考 80–400 条 / 5 小时。
Pro 20x参考 300–1600 条 / 5 小时。
超出限额Plus / Pro 可购买额外积分，不必立刻升级套餐。
这些数字只是教程快照，用来建立量感；购买前一定重新查看官方 pricing 页。
05 · 让额度更耐用：先省 token，再考虑升档
✓提示具体：写明文件、函数、目标和验收标准，减少 Codex 猜测和乱翻。
✓AGENTS.md 瘦身：根目录保持短小，复杂项目按子目录分层。
✓MCP 按需开：不用的 server 关闭，别让工具描述每次都占上下文。
✓常规任务换小模型：硬任务再用更强模型，别全程满功率。
✓切换无关工作用 /new，不要让旧上下文一直重复计费。
模糊“帮我改进这个项目”
具体“改 src/auth.ts 的 login，加入输入校验并补测试。”

08 · 计费篇小结
真正要管理的是上下文
  • 付费对象：模型算力，不是 Codex 安装包。
  • 两套逻辑：订阅走限额 + 积分，API key 走 token 实时扣费。
  • 套餐路线：个人 Plus 起步，重度再看 Pro，团队看 Business 以上。
  • 限额意识：5 小时窗口是量感，不是永恒不变的固定数字。
  • 省钱方法：提示具体、规则瘦身、MCP 按需、小模型、/new 清上下文。
先看清两本账，再放心让它干活
价格和额度会变，使用方法可以沉淀：先看当前官方定价，再用 /status 观察自己的真实消耗。
