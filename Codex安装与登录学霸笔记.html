Codex 安装与登录
Mac / Windows / Linux：从选入口到跑通第一个任务
来源：AI 编程指南 · 03 安装与登录 ｜ 更新 2026.06.20
01 · 开装前，先确认三件事
选入口→ 有账号→ 通网络→ 再敲命令
入口桌面 App：图形界面，适合不爱终端的人；CLI：三平台都支持，开发者最通用。
账号ChatGPT 套餐可用 Codex；也能用 OpenAI API key 按量付费，但部分 ChatGPT 工作区功能会受限。
网络安装、登录和运行都要连 OpenAI；下载超时、回调失败，先检查代理和网络连通性。
版本、套餐和可用功能会变化；遇到细节，以当前官方文档和本地命令输出为准。
02 · 路线一：桌面 App
桌面 App 像“带工程目录的 ChatGPT”：绑定一个本地文件夹，在里面读文件、改代码、跑命令，并提供可视化 diff。
macOS Apple Silicon
下载默认包 macOS Intel
选择 Intel build Windows
下载官网安装包 Linux
暂无桌面 App，先用 CLI
1打开 chatgpt.com/codex，下载对应安装包。
2首次打开：登录 ChatGPT 账号或 API key。
3选项目文件夹，确认 Local，再发第一条任务。
Mac 分不清芯片？“关于本机”里写 Apple M 系列就是 Apple Silicon，写 Intel 就选 Intel build。
03 · 路线二：CLI，三平台通用
首选：官方独立安装器
不依赖 Node.js，直接下载独立二进制；Homebrew 和 npm 作为备选。
# macOS / Linux
curl -fsSL https://chatgpt.com/codex/install.sh | sh

# Windows PowerShell
powershell -ExecutionPolicy ByPass -c "irm https://chatgpt.com/codex/install.ps1 | iex"
官方脚本无前置依赖，独立二进制，更新路径最直接。
Homebrewbrew install --cask codex，适合已经重度使用 brew 的 macOS 用户。
npmnpm install -g @openai/codex，需要 Node.js；遇到权限问题不要直接用 sudo 硬顶。
脚本装完关掉终端再开一个，让 PATH 生效；无人值守脚本可设置 CODEX_NON_INTERACTIVE=1。
04 · Windows：原生还是 WSL2？
原生 + elevated
默认首选，安全性和性能最好 原生 + unelevated
公司策略卡住 elevated 时的退路 WSL2
项目本来就在 Linux 工具链里
Windows 11 是更稳的基线；Windows 10 至少要 1809。winget 要能用，WSL1 已不支持。
# 需要 Linux 环境时，在管理员 PowerShell 中
wsl --install
wsl

# 进入 WSL 后重新安装 CLI
curl -fsSL https://chatgpt.com/codex/install.sh | sh
codex
WSL 性能坑：仓库放在 ~/code 等 Linux 主目录；放在 /mnt/c/... 会拖慢 I/O，并可能带来权限和链接问题。
05 · 安装后先验证，再登录
codex --version
看到版本号CLI 已安装；再用 codex --help 看当前版本支持的参数。
找不到命令先查 PATH，不要条件反射重装；Windows 改 PATH 后要重启终端。
进入项目目录运行 codex。默认登录路线是浏览器授权的 ChatGPT 账号；API key 更适合 CI / 自动化。
✓ChatGPT 账号：大多数人首选，可使用套餐权益和云端功能。
✓API key：按标准 API 价格计费，适合无人值守脚本；部分工作区功能不可用。
~/.codex/auth.json 里的 access token 要当密码看：不要提交 Git、不要贴工单、不要发聊天。
06 · 远程登录：浏览器不在这台机器怎么办？
服务器、无图形界面或 localhost 回调被拦时，浏览器登录容易卡住。优先使用设备码登录：
codex login --device-auth
首选设备码：在另一台有浏览器的设备打开链接、输入一次性验证码。
退路一在本机正常登录后，把 ~/.codex/auth.json 拷到远程同一路径。
退路二SSH 转发回调端口：ssh -L 1455:localhost:1455 user@remote。
07 · 从零跑通第一次
mkdir codex-test && cd codex-test
codex
1启动并完成登录。
2用大白话下指令：在 test.py 里写一个打印 hello world 的函数。
3看清 Codex 要做什么，点 Yes 才让它真正执行。
4动手前后保存 Git 检查点，必要时可以回滚。
git init
git add -A && git commit -m "codex 动手前的检查点"
稳定节奏
安装 → 登录 → 描述目标 → 看动作 → 你确认 → Codex 修改 → Git 验证。
08 · 报错速查：先对症，再下药
command not found安装目录不在 PATH；确认目录、补 PATH、重启终端。
not recognizedWindows 同类 PATH 问题；配好后重新打开 PowerShell。
irm 不识别你在 CMD 里跑了 PowerShell 命令；换 PowerShell。
下载超时网络或代理未通；检查 OpenAI 域名访问。
登录转圈远程 / headless / localhost 回调失败；使用设备码登录。
版本打架可能装了多个 Codex；用 which -a codex 找重复项。
# macOS / Linux 示例：让本地安装目录进入 PATH
echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.zshrc
source ~/.zshrc
codex --version
09 · 安装篇小结
拿到“可用”比拿到“已安装”更重要
  • 选入口：CLI 跨平台；桌面 App 只有 macOS / Windows。
  • 选安装：CLI 优先官方脚本，Homebrew / npm 备选。
  • 选 Windows 路线：原生 elevated 首选，unelevated 退路，Linux 工具链才上 WSL2。
  • 选登录：ChatGPT 账号适合日常，API key 适合自动化；远程优先设备码。
  • 选验证：codex --version、首个小任务、Git 检查点，三步确认真的能用。
装好只是起点，验证才算通关
