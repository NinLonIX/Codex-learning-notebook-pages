Codex CLI 入门
命令骨架、TUI、选项、斜杠命令与 exec
来源：AI 编程指南 · 08 命令行 CLI 上手 ｜ 教程更新 2026.09.01
01 · codex 命令的四块骨架
codex [子命令] [选项...] [提示词]
主命令 ｜ 换跑法 ｜ 调参数 ｜ 要干的活
主命令codex：不带子命令时进入交互式 TUI。
子命令exec 非交互执行，resume 恢复会话，login 登录。
选项以 -- 或 - 开头，控制模型、沙箱和工作目录。
提示词任务描述；可省略后进入界面慢慢聊。
codex
codex "解释一下这个项目的结构"
codex --model <模型名> --cd ~/my-project "把 README 补全"
02 · TUI 先认住三块
对话区：看它干什么+输入框：你发指令+状态栏：看读数
对话区计划、代码、Git diff 和工具输出。
输入框提示词、代码、截图和斜杠命令。
状态栏模型、上下文余量、工作目录和 Git 分支。
屏幕花了按 Ctrl+L 重绘；它不丢对话。/clear 才会开启新对话。
03 · 高频启动选项
-m / --model临时切模型。
-s / --sandboxread-only / workspace-write / danger-full-access。
-a / --ask-for-approvaluntrusted / on-request / never。
-C / --cd直接指定工作目录。
--add-dir额外放开可写目录。
-i / --image把截图或设计稿作为输入。
--search本次开启实时联网搜索。
--oss使用本地开源模型，需要 Ollama。
--yolo / --dangerously-bypass-approvals-and-sandbox 会绕过审批和沙箱，新手不要使用。
04 · 斜杠命令：会话遥控器
/model 切模型 ｜ /permissions 调权限 ｜ /status 看状态 ｜ /diff 看改动
/compact 压缩上下文 ｜ /review 独立审查 ｜ /init 生成 AGENTS.md ｜ /clear 新对话
任务运行时可以先输入下一条，用 Tab 排队，当前轮结束后自动执行。
05 · 键盘动作与前缀
Ctrl+C中断或退出。
Ctrl+L重绘屏幕，保留上下文。
↑ / ↓翻草稿历史。
Ctrl+R反向搜索提示词历史。
Ctrl+O复制最近一条输出。
Ctrl+G在外部编辑器写长提示词。
! / @! 跑 shell；@ 搜索并插入文件路径。
!git status
@src/auth.ts
06 · 五分钟验证流程
1建目录并启动：mkdir -p ~/codex-cli-demo && cd ~/codex-cli-demo; codex。
2输入 /status，确认模型、权限、目录和上下文。
3输入 !echo hello-codex-cli，确认 shell 模式。
4按 ↑，确认草稿历史能调回。
5让它新建 hi.txt，再用 /diff 查看改动。
6输入 /exit 或 Ctrl+C 退出。
如果建文件时没有弹审批，说明当前策略允许工作区内写入；这是权限配置的结果。
07 · 交互式 vs codex exec
交互式进入 TUI，边看边聊边调整；适合探索、调试和人工判断。
exec一句话执行、输出后退出；适合脚本、CI、批量和定时任务。
机器读取--json 输出事件，-o 保存最终消息。
codex exec "审查当前改动，列出潜在 bug"
exec 没有人在场点确认，权限和沙箱要提前配好；不要在重要项目上无隔离地自动运行。
08 · CLI 入门小结
CLI 是功能更全、可自动化的那条线
  • 命令：主命令 + 子命令 + 选项 + 提示词。
  • 界面：TUI 认对话区、输入框、状态栏。
  • 启动：先用 -m、-s、-a、--cd 控制环境。
  • 会话：/status、/diff、/review 是日常核心。
  • 自动化：脚本化就用 codex exec。
黑窗口只是外壳，CLI 才是自动化入口
先把 TUI 和高频命令用顺，再把 exec 接进脚本、CI 和定时任务。
