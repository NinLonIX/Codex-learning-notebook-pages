Codex 桌面 App 全景
并行线程 × Worktree 隔离 × 可视化审阅 × 自动化工作台
来源：AI 编程指南 · 07 桌面 App 全景 ｜ 更新 2026.06.20
01 · 先认清定位：它不是 CLI 的简化版
桌面 App = 为并行和可视化打造的代码工作台
它和 CLI、IDE 扩展使用同一个 Codex，共享 AGENTS.md、MCP 和 Skills；差别在于把多个线程、项目、审阅和自动化集中到一个窗口。
多个线程+ 隔离环境+ 图形审阅→ 并行工作台
适合同时修 bug、补测试、跑长任务，或边改代码边在内置浏览器里看效果。
02 · 平台与登录：两个桌面平台，Linux 先用 CLI
macOS Apple Silicon
下载默认包 macOS Intel
选择 Intel build Windows
Microsoft Store / winget Linux
暂无桌面 App，先用 CLI
推荐登录ChatGPT 账号：桌面 App 功能更完整，适合日常和云端能力。
API key部分功能可能受限；遇到云端能力变灰，先检查登录方式。
Mac 先确认 Apple Silicon / Intel；Linux 没有漏装组件，是官方暂未提供桌面 App。
03 · 三栏心智模型：左边去哪，中间干活，右边验收
左边栏：项目 / 线程→ 中间：对话 / 执行→ 右边：Diff / 终端 / 预览
左边栏新线程、搜索、插件、Automations、Projects、Chats。
中间区对话流、输入框、模型选择、权限选择、Local / Worktree / Cloud 模式。
右边面板Diff 审阅、共享工作区的内置终端、网页 / 文件 / 图片预览。
Project 能绑定文件夹并改代码；普通 Chat 不绑定项目，适合研究、规划和调插件。
04 · 三种运行模式：Local / Worktree / Cloud
Local
本机当前目录
日常开发、立即见结果 Worktree
本机隔离副本
并行任务不互相覆盖 Cloud
OpenAI 云端沙箱
长任务后台运行
同一项目要并行多个任务时优先 Worktree。它依赖 Git，只继承 Git 中的文件；.env、node_modules 等被忽略的内容不会自动带过去。
Worktree 记忆点
Git 仓库是前提 ｜ 每个任务一份副本 ｜ 默认不污染主目录 ｜ Handoff 可交回 Local
05 · 可视化审阅：把 diff 变成可操作的 Review pane
✓按未提交改动、分支差异、最近一轮改动切换查看范围。
✓逐行内联批注：点某行的 +，写反馈后让 Codex 按批注修改。
✓按整份 diff、文件、hunk 暂存、取消暂存或回滚。
✓满意后直接 commit、push、创建 Pull Request。
审阅面板依赖 Git 仓库，显示的是仓库未提交状态，不一定只有 Codex 本轮改动。
06 · CLI 给不了的四个工作台能力
Review pane逐行批注、按块回滚、可直接提交和开 PR。
内置终端与当前项目 / Worktree 共享同一目录，Codex 也能读终端输出。
Actions把测试、开发服务器、格式化等常用命令做成顶部按钮。
Automations按天、周或线程计划自动运行；App 要开着，项目要在磁盘上可用。
Local Environments 中的设置脚本可在新 Worktree 建立时补依赖，Actions 负责手动触发常用命令。
07 · 快捷键与斜杠命令：先记高频的
Cmd + K打开命令菜单；Windows 键位以 Settings > Keyboard Shortcuts 为准。
Cmd + N新建线程。
Cmd + J切换内置终端。
Cmd + Option + B切换 Diff 审阅面板。
Ctrl + L清空终端；不要把 Cmd + K 当清屏。
/status 看线程、上下文和限额
/review 开代码审查
/plan 切换计划模式
/mcp 查看 MCP 状态
08 · 从打开到跑通第一个并行任务
1选择 Git 项目，模式选 Worktree。
2发一个小任务：实现 TODO 或补 README 运行说明。
3再开第二个 Worktree 线程，做另一项不相关的任务。
4在 Review pane 逐行批注、按 hunk 暂存或回滚。
5满意后 commit / push；需要主目录时用 Handoff 回 Local。
并行不打架的关键
每个线程各自拥有 Worktree 副本；审阅通过之前，主目录保持干净。
09 · 桌面 App 速记
左边挑去哪，中间让它干，右边看结果
  • 定位：同一个 Codex，为并行与可视化打造的工作台。
  • 模式：Local 直改、Worktree 隔离、Cloud 后台。
  • 核心优势：Review pane、共享终端、Actions、Automations。
  • 并行规则：同一项目多个任务，优先 Worktree；Git 是前提。
  • 快捷入口：Cmd + K、Cmd + N、/status、/review。
把多个线程，放进同一张工作台
桌面 App 的价值不是少敲几条命令，而是让并行、隔离、审阅和自动化在同一窗口里形成稳定节奏。
